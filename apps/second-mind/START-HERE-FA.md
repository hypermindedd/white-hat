# SECOND MIND — مستقل — 0.3.0-alpha.1

این بسته برنامهٔ اجرایی و سورس نسخه alpha است؛ نصب‌کننده بومی یا محصول تجاری تأییدشده نیست.

۱. Node 24.15 یا بالاتر از خانواده 24.x روی دستگاه نصب باشد.
۲. از همین پوشه npm start را اجرا کنید و آدرس محلی نمایش‌داده‌شده را باز کنید.
۳. حساب مدیر خودتان را بسازید؛ رمز یا حساب پیش‌فرض وجود ندارد.
۴. مدل و کلید API دارای دسترسی را در تنظیمات وارد کنید. کلید را در چت/کد قرار ندهید.

راهنمای کامل: README-FA.md. نقشه ۱۰فازی در docs/ROADMAP-FA.md؛ وضعیت ۴۴ قابلیت در product/commercial-scope.json؛ شواهد ۲۳ تست نرم‌افزاری در evidence/standalone/test-report.json.

کلید واقعی در محیط ساخت نبود و اجرای مدل زنده صفر است. پاسخ fixture فقط در تست‌های جدا استفاده شده و در برنامه کاربر جایگزین AI نمی‌شود. مرورگر تا صفحه آغاز بررسی شد؛ صفحات احراز‌شده نیازمند آزمون کاربر هستند.

launcher مک/ویندوز برای اجرای توسعه با Node نصب‌شده است؛ DMG/EXE امضاشده ساخته نشده. پرداخت، tenant production، ورودی چندرسانه‌ای، ممیزی امنیت، backup/restore و benchmark واقعی موتور هنوز بازند.

بخش GPT قدیمی در این توزیع وجود ندارد. این بسته خروجی مستقل و قابل‌بررسی این مرحله است؛ ثبت جدیدی در GitHub انجام نشده.
