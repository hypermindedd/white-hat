# ADR-009 — تغییر مسیر رسمی به محصول مستقل

تاریخ: 2026-11-03. مبنا: دستور صریح مالک محصول در همین مرحله: سیستم مستقل قابل‌تجاری‌سازی با پنل کامل؛ وب‌اپ یا نصب مک/ویندوز؛ عدم ساخت GPT.

**تصمیم فعال:** Web-first مستقل → ارزیابی مستقیم موتور API → سخت‌سازی تجاری → بسته‌های بومی مک و ویندوز از همان هسته. ساخت، نصب و آزمون GPT Builder از مسیر فعال حذف شد. اصلاحیه GPTs-first در snapshotهای تاریخی به‌عنوان تاریخچه باقی می‌ماند و دیگر ترتیب اجرای جاری را تعیین نمی‌کند.

| موضوع | اثر بازنگری |
|---|---|
| Runtime | سرور مستقل، UI مستقل، adapter مدل و قرارداد خروجی کدی |
| ارزیابی | همان ۱۵ بُعد و ≥۶۰ کیس، مستقیماً روی موتور API؛ بدون وابستگی به Custom GPT |
| رابط/داده | همزمان با موتور یک برش واقعی حساب، داده، مدیریت و تاریخچه ساخته می‌شود |
| GPT package قبلی | legacy؛ منبع تاریخی است، تحویل فعال یا پیش‌نیاز ساخت نیست |
| وب/دسکتاپ | یک Core و API؛ ابتدا وب‌اپ قابل‌اجرا روی localhost، سپس shell بومی امضاشده |
| تجاری‌سازی | هویت production، tenant، پرداخت، عملیات و کیفیت گیت مستقل دارند |
| Scope شناختی | ۷ Mode/۱۱ Core/۸ Conditional حفظ؛ چندعاملی، حافظه شناختی و اقدام خودکار اضافه نشده |
| مرجع مفقود | G01 درباره سند Canonical تاریخی باز می‌ماند؛ این دستور مالک، مسیر فنی جاری را روشن کرده |
| Freeze لاگ | G10 بدون ساخت failure مصنوعی باز می‌ماند؛ مانع اعلام Freeze کامل است، نه ساخت alpha |

## معماری قابل‌بررسی

`apps/second-mind` یک برنامه چندفایلی واقعی است: سرور Node.js، SQLite پایدار، وب‌پنل، session/role، ثبت run، provider API، validation و ارزیابی انسانی. مسیر پیش‌فرض loopback است. نسخه فعلی یک workspace با جداسازی دادهٔ اعضاست؛ محصول multi-tenant سازمانی هنوز ساخته نشده.

واسط مدل قابل‌جایگزینی است؛ adapter فعلی OpenAI Responses است. استفاده از API یک مدل، ساخت GPT سفارشی نیست. مدل و کلید در تنظیمات/محیط سرور تعیین می‌شوند؛ هیچ مدل یا دسترسی حسابی فرض نشده. کلید واقعی در محیط ساخت موجود نبود و اجرای زنده انجام نشد.

## اثر بر شواهد قبلی

۱۲ تست RC0 فقط بسته‌بندی GPT قدیمی را می‌سنجیدند و برای محصول مستقل اعتبار اجرایی ندارند. معیار کیفیت reasoning حفظ می‌شود؛ ۲۳ تست جدید، برنامه و adapter را با provider fixture جداگانه می‌سنجند. هیچ fixture به‌عنوان پاسخ واقعی AI یا امتیاز benchmark ثبت نشده.

بررسی مرورگر تا صفحه آغاز/ساخت حساب انجام شد. صفحات احراز‌شده در مرورگر به ساخت حساب کاربر نیاز دارند و این مرحله از طرف کاربر انجام نشده؛ این بخش با تست API یکی اعلام نمی‌شود. آزمون امنیت production یا آزمون نصب‌کننده بومی ادعا نمی‌شود.

## بازگشت و کنترل تغییر

منابع ۱۷گانه اصلی تغییر نمی‌کنند. مسیر قدیمی بازنشسته و در README/STATUS مشخص می‌شود. بازگشت کد با نسخه قبلی source؛ داده alpha در مسیر مستقل سیستم کاربر است و در بسته سورس قرار نمی‌گیرد. قبل migration بعدی، backup و restore مستقل لازم است. هیچ rollback دادهٔ تجاری در این نسخه ادعا نشده.
