# اشکال‌های واقعی ابزار و یکپارچگی این مرحله

این‌ها اشکال نرم‌افزار/محیط توسعه‌اند؛ شکست واقعی هوشمندی برای شرط LOG-001 محسوب نمی‌شوند و برای پرکردن تعداد شکست‌ها ساخته نشده‌اند.

| ID | مشاهده | علت ریشه‌ای | اصلاح و دامنه رگرسیون |
|---|---|---|---|
| APP-001 | preview در مهلت مقرر healthy نشد؛ CLI پورت 4173 داده بود و برنامه روی 4317 بود | launcher آرگومان host/port را نمی‌خواند | parser صریح CLI و origin configuration؛ preview از مسیر رسمی اجرا و صفحه آغاز در مرورگر دیده شد |
| APP-002 | پس از ساخت تنظیم origin پیش‌نمایش، ۱۷ تست API با 403 در setup شکست خوردند | config پیش‌نمایش به‌طور ضمنی به همه instanceهای factory سرایت می‌کرد | حذف config ضمنی از factory و تزریق resolver از launcher؛ رگرسیون کامل ۲۳ تست |

خودممیزی همچنین edit/switch-mode را به قرارداد جدا تبدیل کرد: ویرایش ورودی، context قدیمی را invalidate می‌کند؛ تغییر Mode تنها، context همان تصمیم را حفظ می‌کند. این مورد به‌عنوان شکست AI ثبت نشده؛ انتظار مشخص و تست regression به برنامه اضافه شده است.

شماره نسخه میانی یا پاس‌های قبل از اصلاح جای نتیجه رگرسیون نهایی را نمی‌گیرد. شواهد نهایی در test-report نگه‌داری می‌شود؛ اجرای واقعی مدل هنوز صفر است.
