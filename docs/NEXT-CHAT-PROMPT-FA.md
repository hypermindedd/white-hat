# پرامپت ادامه مرحله بعد
در مخزن hypermindedd/white-hat پروژه SECOND MIND را از نسخه 0.1.0-docs ادامه بده. ابتدا README، INDEX، STATUS، GAPS و ROADMAP را بخوان. دامنه V1 Frozen است؛ یک مدل با reasoning چندمرحله‌ای، ۷ Mode، ۱۱ Core و ۸ Conditional. هدف مرحله بعد RC0 و بسته اجرایی GPT است؛ Runtime Knowledge فقط ۰۱ تا ۰۷، ارزیابی KNOW-08 و EVALها بیرون Runtime. ابتدا تعارض‌ها و traceability را ببند، سپس دستور مناسب نصب و ۷ فایل را استخراج کن و کیس‌های کامل smoke هفت Mode را بساز. از وجود اسناد نتیجه PASS نگیر؛ نتیجه واقعی بدون اجرای Runtime اعلام نکن. هر تغییر version، دلیل، منبع و rollback داشته باشد.
