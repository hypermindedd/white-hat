## تقدم تخصصی

دامنه محصول از Product Specification و اصلاحیه‌های صریح آن پیروی می‌کند. مرجع Canonical Product Definition جداگانه هنوز پیدا نشده و در GAPS باز است.

| موضوع | مرجع |
|---|---|
| Decision Object | KNOW-01 |
| Core / Conditional | KNOW-02 / KNOW-03 |
| وزن و تنظیم Mode | KNOW-04 |
| شواهد و اطمینان و حکم | KNOW-05 |
| خروجی قابل‌مشاهده | KNOW-06 |
| ترتیب اجرا و Routing | KNOW-07 |
| ارزیابی و failure namespace | KNOW-08 / EVAL-001 |
| اعتبار ارزیابی | EVAL-002 |
| خطا و رگرسیون | LOG-001 |
| تصمیم انتشار | REL-001 |

اصلاحیه‌های صریح ممیزی نسبت به متن قدیمی همان موضوع تقدم دارند؛ تاریخ ویرایش به‌تنهایی دلیل تقدم نیست. تعارض تازه باید ثبت شود، نه با سلیقه حل و در اسناد پنهان شود.
Runtime Knowledge=KNOW-01…07؛ KNOW-08 و اسناد ارزیابی/حاکمیت در بسته ارزیابی می‌مانند.
