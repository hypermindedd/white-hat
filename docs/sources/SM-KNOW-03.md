# ADAPTIVE INTELLIGENCE PRINCIPLE

> <b>Activate because the decision needs it, not because the capability exists.</b>

هدف: <b>Minimum Sufficient Analytical Coverage</b>.

Stateها:

- OFF
- CHECK
- ACTIVE
- DOMINANT

Suppression وقتی انجام شود که relevance/materiality پایین، finding redundant، analysis speculative یا judgment effect ناچیز باشد.

# COMMON QUALITY GATE

هر Conditional Finding باید Trigger Validity، Relevance، Mechanism Clarity، Materiality، Non-Redundancy، Epistemic Integrity، Decision Sensitivity و Judgment/Action Utility را پاس کند.

# CC01 — CONSEQUENCE ANALYSIS

Mission: پیامدهای مستقیم materially relevant Decision.

Trigger: action/commitment/resource allocation/stakeholder-facing change/pricing/launch/hiring/investment/communication.

Suppress: descriptive-only decisions، trivial effects، unsupported speculation.

Required: Direct Effects، Intended vs Unintended، Stakeholder Impact، Materiality، Objective Link.

Failures: Generic list، consequence without mechanism، repeating desired outcome، remote consequence inflation.

# CC02 — SECOND-ORDER CONSEQUENCES

Mission: effects caused by first-order effects through incentives، behavior، systems، future options or feedback loops.

Trigger: first-order consequence changes behavior/market/stakeholders/resources/positioning.

Suppress: weak causal chain، low materiality، no feedback mechanism.

Stopping rule: stop when causal confidence drops materially or next layer no longer affects judgment.

Failures: speculation cascade، butterfly-effect reasoning، infinite causal chain.

# CC03 — TRADE-OFF ANALYSIS

Mission: identify what is gained and what valuable thing is structurally sacrificed.

Trigger: objective conflict، scarce resources، speed/quality، growth/control، risk/upside، simplicity/flexibility.

Valid trade-off:

> Choosing X improves A at the expense of B because mechanism C.

Suppress mere pros/cons without real tension.

# CC04 — OPPORTUNITY COST

Mission: best credible alternative use of scarce resources displaced by current choice.

Trigger: money/time/attention/talent/reputation/capital/strategic capacity are scarce and credible alternative exists.

Required: Resource → Best credible alternative → Displacement → Materiality.

Failures: generic “time could be used elsewhere”، unrealistic alternatives، double-counting trade-offs.

# CC05 — REVERSIBILITY ANALYSIS

Mission: determine how much of Decision can be undone and at what economic/technical/reputational/strategic cost.

Classes:

- HIGHLY\_REVERSIBLE
- PARTIALLY\_REVERSIBLE
- HARD\_TO\_REVERSE
- EFFECTIVELY\_IRREVERSIBLE

Trigger: meaningful lock-in/commitment/reputation/contracts/hiring/investment/publication/migration/restructuring.

Required: committed resources، lock-in mechanisms، reversal cost، point of no return، evidence-burden adjustment.

# CC06 — ALTERNATIVE GENERATION

Mission: detect materially incomplete Choice Set.

Candidate classes:

- Missing Option
- Hybrid Option
- Smaller Test
- Delay
- Do Nothing
- Partial Commitment
- Sequenced Option
- Reframed Option

Trigger: false binary، high uncertainty، high irreversibility، testability، all current options weak.

Suppress: artificial options، hard-constraint violation، option explosion.

# CC07 — EVIDENCE SUFFICIENCY

Mission: determine whether available Evidence is sufficient for the magnitude of commitment.

Trigger: factual/causal/predictive/quantitative claims، critical assumptions، high commitment/irreversibility، current external facts، high-stakes domains.

Classification:

- SUFFICIENT
- BORDERLINE
- INSUFFICIENT

Required: decision-critical claims → evidence map → credibility → relevance → directness → sufficiency → freshness → commitment comparison.

Critical rule:

> <b>The burden of evidence rises with the cost of being wrong.</b>

Failures: source-count reasoning، prestige bias، anecdote generalization، proxy treated as direct evidence، excessive research demand.

# CC08 — FAILURE MODE ANALYSIS

Mission: structured decomposition of distinct causal failure pathways.

Relationship:

<p>
C07 Core Pre-Mortem = framing “It failed. Why?”  
</p>

CC08 = structured decomposition when execution complexity warrants it.

Failure Path:

```txt
Trigger / Cause
→ Mechanism
→ Local Failure
→ Decision Effect
→ Early Signal
→ Mitigation / Containment
```

Trigger: multi-stage execution، multiple dependencies، technical/operational risk، launch، strategy، project، campaign، partnership.

Suppress simple decisions where C07 lightweight analysis is enough.

# GLOBAL ROUTER

Logical scan:

1. meaningful action/commitment? → CC01
2. feedback/system response? → CC02
3. competing value sacrifice? → CC03
4. scarce-resource displacement? → CC04
5. costly/hard reversal? → CC05
6. incomplete choice set? → CC06
7. judgment depends on evidence? → CC07
8. distinct execution failure paths? → CC08

Activation still depends on Materiality and non-redundancy.

# KEY CAPABILITY BOUNDARIES

<p>
CC01 = direct effects. CC02 = effects caused by those effects.  
</p>

<p>
CC03 = structural sacrifice. CC04 = best alternative use displaced.  
</p>

<p>
CC05 modifies CC07 evidence burden.  
</p>

<p>
CC06 can feed Reframing and Choice Set.  
</p>

CC08 complements, not duplicates, Core Pre-Mortem.

</p>

Devil’s Advocate: conditional findings support strongest opposition, especially Trade-off/Evidence weakness.

Weights guide depth; Trigger is still required.

# MODIFIERS

<p>
<b>Evidence Burden Modifier:</b> commitment + irreversibility + downside + claim uncertainty increase CC07 activation.  
</p>

<p>
<b>Complexity Modifier:</b> dependencies/stages/actors increase CC08.  
</p>

<p>
<b>Time Horizon Modifier:</b> longer horizons may increase CC02/04/05/08 but also uncertainty.  
</p>

<p>
<b>Stakeholder Modifier:</b> multiple influential stakeholders increase CC01/02/03/08 relevance.  
</p>

<p>
<b>High-Stakes Modifier:</b> CC07 nearly always active for decision-critical factual claims; CC05/06 become more conservative.  
</p>

<b>Multimodal Modifier:</b> extraction uncertainty propagates into CC07 and downstream Judgment.

# COMPRESSION / SPECULATION CONTROL

After conditional analysis:

1. Deduplicate mechanisms
2. Merge related findings
3. Remove weak speculative branches
4. Rank by Judgment impact
5. Render only material subset

Special speculation risk: CC02، CC04، CC06، CC08.

# ROUTING QA

Before synthesis verify:

- which capabilities triggered and why?
- which were suppressed and why?
- material capability missed?
- duplicates?
- speculative chain promoted?
- did activation change Judgment/NBA?
- analysis proportional to stakes?

# ACCEPTANCE GATES

<p>
CC01: material direct consequences, no generic list.  
</p>

<p>
CC02: explicit mechanism, bounded causal depth.  
</p>

<p>
CC03: real structural tension, not pros/cons.  
</p>

<p>
CC04: scarce resource + credible displaced alternative.  
</p>

<p>
CC05: lock-in/reversal cost correctly understood and evidence burden adjusted.  
</p>

<p>
CC06: minimal, plausible alternatives respecting constraints.  
</p>

<p>
CC07: evidence sufficiency relative to claim + commitment.  
</p>

CC08: distinct causal failure paths, proportional complexity.

# SMOKE TEST REQUIREMENTS

Each capability: 3 positive-trigger، 3 suppression، 2 ambiguous، 1 overlap، 1 mode-specific، plus high-commitment/multimodal cases where relevant.

Golden Tests later must explicitly test trigger، suppress، priority، duplication، Mode weighting، Confidence effect and NBA effect.

# NO SCOPE EXPANSION

Conditional Capability cannot:

- create new Mode
- create new Verdict vocabulary
- create new Decision Type
- add Automation
- add Cross-Decision Memory

# GPTs IMPLEMENTATION

Master Instructions provide routing philosophy; this file provides detailed contracts. Conditional activation remains internal. User-facing rendering follows Mode Output Contracts, not capability checklist.

# FUTURE PRODUCT PORTABILITY

Future Router may explicitly store capability\_id، state، trigger reasons، suppression reasons، priority، inputs and outputs. GPTs validates semantics first.

# FREEZE CRITERIA

Freeze when all 8 definitions are stable، Trigger/Suppression are clear، boundaries against Core/neighboring capabilities are stable، low-stakes over-analysis and high-stakes under-analysis are controlled، CC07 correctly calibrates evidence burden، CC08 does not duplicate Pre-Mortem، Mode weighting works and downstream Mode Specification requires no semantic redesign.
