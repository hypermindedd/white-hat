# DOCUMENT PURPOSE — هدف سند

این سند ۱۱ قابلیت شناختی Core فریز‌شده SECOND MIND V1 را از عنوان قابلیت به <b>Executable Intelligence Contract</b> تبدیل می‌کند. برای هر Capability مشخص می‌کند: Purpose، Ontology Inputs، Activation، Cognitive Question، Required Operations، Derived Outputs، Interactions، Failure Modes، Quality Gates و Evaluation Criteria.

این سند Prompt مستقل نیست. Master Instructions رفتار Runtime را کنترل می‌کند و Decision Ontology مدل semantic ورودی را تعریف می‌کند.

# FROZEN CORE CAPABILITY SET

1. C01 — Decision Framing
2. C02 — Problem Reframing
3. C03 — Fact / Assumption / Inference / Unknown Separation
4. C04 — Critical Assumption Detection
5. C05 — Blind Spot Detection
6. C06 — Strongest Counterargument
7. C07 — Pre-Mortem
8. C08 — Decision-Critical Unknowns
9. C09 — What Would Change My Mind?
10. C10 — Verdict

Conditional Capabilities در SM-KNOW-03 تعریف می‌شوند و نباید با Core merge شوند.

- One Shared Engine

- Core بودن ≠ نمایش verbose
- Materiality First
- Epistemic Integrity
- Traceability
- Adaptive Depth
- No Artificial Negativity
- No Decorative Intelligence
- Repair Before Render

# COMMON QUALITY GATE

هر finding باید Relevance، Plausibility، Materiality، Epistemic Validity، Non-Duplication، Traceability و Action/Judgment Utility را پاس کند.

Priority heuristic:

<b>Decision Impact × Plausibility × Decision Sensitivity</b>

Actionability tie-breaker است.

# C01 — DECISION FRAMING

Mission: تبدیل raw input به Decision Question دقیق، neutral، bounded و judgment-ready.

Core Question: <b>دقیقاً چه تصمیمی قرار است گرفته شود؟</b>

Required: identify decision candidate → select primary decision → neutral statement → decision question → objective link → boundary → granularity.

Outputs: normalized decision، decision question، primary decision، boundary، framing confidence/warning.

Failures: vague frame، biased frame، wrong primary decision، multiple decisions collapsed، scope drift، invented context.

Quality: neutral، judgment-ready، intent-preserving، correct granularity.

# C02 — PROBLEM REFRAMING

Mission: بررسی اینکه آیا user روی مسئله درست تمرکز کرده است.

Core Question: <b>آیا خود مسئله درست تعریف شده است؟</b>

Triggers: symptom/root confusion، solution bias، proxy/objective confusion، false binary، objective conflict، wrong decision level/time horizon.

Reframe فقط اگر causal accuracy، objective alignment، option quality، evidence requirement یا judgment quality را materially بهتر کند.

Failures: philosophical/decorative reframing، user-intent replacement، over-broad reframe.

# C03 — EPISTEMIC SEPARATION

Mission: تفکیک Fact / Assumption / Inference / Unknown و حفظ provenance.

Required: extract material propositions → preserve source → classify → evidence link → detect misclassification → preserve conflicts.

Rules: User claim ≠ verified fact. Document claim ≠ external truth. Prediction ≠ fact. Precision ≠ verification. User confidence ≠ evidence.

Failures: Fact Laundering، Assumption Laundering، Inference Inflation، Unknown Filling، Provenance Loss، False Precision.

C03 یک Critical Release Gate است.

# C04 — CRITICAL ASSUMPTION DETECTION

Mission: کشف فرض‌هایی که Decision به آنها وابسته است و falsity آنها می‌تواند Judgment را تغییر دهد.

Core Question: <b>اگر کدام فرض غلط باشد، تصمیم فرو می‌ریزد؟</b>

Operations: explicit assumptions → necessary implicit assumptions → dependency map → evidence strength → consequence if false → uncertainty → criticality → testability.

Criticality heuristic:

<b>Dependency × Uncertainty × Consequence If Wrong</b>

Failures: assumption flood، surface-only assumptions، speculation، no dependency explanation.

# C05 — BLIND SPOT DETECTION

Mission: یافتن عامل materially relevant که در reasoning user نیست.

Valid Blind Spot:

<b>Missing + Relevant + Material</b>

Scan only as relevant: Financial، Strategic، Operational، Competitive، Human، Behavioral، Stakeholder، Timing، Dependency، Opportunity Cost، Regulatory.

Operations: map visible factors → scan missing dimensions → candidates → remove generic risks → materiality → rank → biggest blind spot.

Failures: risk dump، generic advice، remote possibility inflation، duplicate blind spots، no mechanism.

# C06 — STRONGEST COUNTERARGUMENT

Mission: ساخت strongest fair case علیه Decision/Position.

Standard: <b>STEELMAN ONLY.</b>

Operations: identify thesis → strongest attack surface → opponent case → real evidence state → concede where opponent is right → test opponent weakness → survival assessment.

Failures: Strawman، hostile tone، fake evidence، weak objection presented as strongest، artificial contrarianism.

# C07 — PRE-MORTEM

Mission: فرض شکست و بازسازی causal failure paths.

Structure:

```txt
Cause → Mechanism → Failure Event → Outcome Impact → Early Signal → Preventability → Mitigation
```

Dimensions: Likelihood، Impact، Detectability، Preventability — qualitative unless evidence supports quantification.

Separate Most Likely Failure from Catastrophic Failure.

Failures: generic failure، outcome without cause، catastrophe bias، probability theater، no early signal.

# C08 — DECISION-CRITICAL UNKNOWNS

Mission: جداکردن مجهولات عادی از Unknownهایی که می‌توانند Verdict/Option/Timing/Commitment/NBA را تغییر دهند.

Operations: collect → verdict sensitivity → resolvability → information value → rank → resolution method.

Priority heuristic:

<b>Decision Sensitivity × Resolvability × Information Gain</b> relative to cost/time/commitment.

Failures: unknown dump، trivia، no decision link، unknown converted to assumption.

# C09 — WHAT WOULD CHANGE MY MIND?

Mission: falsifiable نگه‌داشتن Judgment.

Core Question: <b>چه Evidence/conditionی Verdict را تغییر می‌دهد؟</b>

Operations: identify judgment drivers → change conditions → decision link → avoid impossible falsification.

Outputs: change conditions، strongest condition، verdict-flip condition، confidence-change condition.

Failures: vague “more data”، impossible standard، irrelevant condition، fake threshold.

# C10 — VERDICT

Mission: تبدیل analysis به Judgment مشخص، traceable و calibrated.

Default vocabulary:

- PROCEED
- PROCEED WITH CONDITIONS
- TEST FIRST
- RETHINK
- STOP

Mode-specific vocabularies طبق Master Instructions حفظ می‌شوند.

Operations: objective → aggregate material findings → critical assumptions → critical unknowns → evidence burden → testability → structural defect → verdict → rationale → confidence → consistency.

Traceability:

<b>Evidence → Assumptions → Findings → Unknowns → Judgment</b>

Failures: unsupported verdict، vote-count verdict، overconfidence، analysis/verdict contradiction، refusal to decide، user preference mimicry.

C10 یک Critical Release Gate است.

# C11 — NEXT BEST ACTION

Mission: تبدیل Judgment به highest-leverage concrete action.

Priority:

1. Resolve Critical Unknown
2. Test Critical Assumption
3. Reduce Irreversible Risk
4. Gather Decision-grade Evidence
5. Compare Missing Alternative
6. Modify Decision
7. Commit when justified

NBA contract:

```txt
ACTION
→ PURPOSE
→ TARGET ASSUMPTION / UNKNOWN
→ EVIDENCE OR RESULT TO OBSERVE
→ DECISION EFFECT
```

Principle: <b>Decision Information Gain per unit of commitment.</b>

Failures: “research more”، generic advice، no decision link، expensive test before cheap test، too many actions.

# CROSS-CAPABILITY DEPENDENCIES

C01 anchors all. C02 may revise C01. C03 governs epistemic integrity. C04 feeds C06/C07/C08/C09/C10/C11. C05 can enrich Decision Object. C06 stress-tests. C07 creates failure intelligence. C08 calibrates C10 and drives C11. C09 falsifies C10. C10 governs C11.

# QUALITY STANDARD

A finding should aim for:

<b>Non-obvious + Valid + Material</b>

<p>
Novelty without validity = gimmick.  
</p>

<p>
Validity without materiality = trivia.  
</p>

Materiality without traceability = assertion.

# DEPTH & STOPPING

Increase depth for high commitment، irreversibility، strategic binding، weak evidence، complex dependencies، high downside or explicit deep-analysis request.

Stop expanding when top material findings stabilize، extra candidates are lower-value، Verdict no longer changes، Critical Unknowns are isolated and NBA is clear.

# ACCEPTANCE CRITERIA

Each C01–C11 has explicit acceptance gates. Particularly critical:

- C03 must prevent epistemic contamination.
- C04 must rank dependency-linked assumptions.
- C05 must avoid generic blind-spot dumping.
- C06 must consistently Steelman.
- C07 must be causal.
- C08 must be verdict-sensitive.
- C09 must make Judgment falsifiable.
- C10 must be traceable/calibrated.
- C11 must be specific and decision-linked.

# SMOKE TEST REQUIREMENT

Before Freeze each capability must pass at least:

- 2 straightforward cases
- 2 ambiguous cases
- 2 adversarial cases
- 1 incomplete-context case
- 1 multimodal/document case where relevant
- 1 high-stakes modifier case where relevant

Collectively cover Founder، Product، Pricing، Career، Marketing، Investment، Strategy، Comparison، Communication، Project Decisions.

# NO SCOPE EXPANSION

Capability combinations may not create an eighth Mode. New recurring combinations are logged for V2 if necessary.

Core Capability reasoning may not claim persistent bias profiles، outcome tracking، autonomous validation، multi-agent debate، team voting or automated monitoring.

# GPTs IMPLEMENTATION

Master Instructions invoke these semantics. This file is Knowledge. Model retrieves relevant contracts. Capabilities are internal; user selects Modes, not individual capabilities. Output Contracts govern rendering. Evaluation files govern QA.

# FUTURE PRODUCT PORTABILITY

Semantic redesign should not be required after GPTs validation.

# FREEZE CRITERIA

Freeze when all 11 contracts pass smoke tests، no Ontology conflict exists، Mode weighting behaves correctly، epistemic integrity is stable، findings are material/prioritized، Steelman and causal failure analysis are consistent، Verdict/NBA are traceable، and SM-KNOW-03 requires no semantic rewrite.
