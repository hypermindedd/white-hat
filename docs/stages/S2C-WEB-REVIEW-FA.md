# راهنمای بازبینی نسخهٔ وب C1/C2

کنترل توقف تحلیل فقط ثبت اجرای جدید را متوقف می‌کند. بازپخش همان درخواست و اجرای ثبت‌شده همچنان معتبرند. اصلاح رسید فقط با مجوز مالک انجام می‌شود. تکرار همان شناسه و داده بی‌اثر است و مبلغ مورد انتظار از بازنویسی اصلاح تازه جلوگیری می‌کند. سابقهٔ قبلی و جدید در دفتر افزایشی ثبت می‌شود. اتصال به صورتحساب عملیاتی باز است.

V7 افزایشی است. حساب اجرایی API به SELECT و INSERT روی run_cost_corrections و SELECT، INSERT و UPDATE روی workspace_analysis_flags نیاز دارد. پاک‌سازی خودکار فقط امتیازهای منقضی را در workspace دارای دورهٔ مصوب حذف می‌کند. سیاست تصمیم‌ها، رسیدها، Audit و backup در محیط مقصد جداگانه لازم است. برگشت پس از write به snapshot تازه و رویهٔ ADR-010 وابسته است.

Quality Engine از مخزن Qullity-engine در SHA 67f3693c5ca3593a1a1eb52f3de54aac40be1cb2 دریافت می‌شود. خروجی GO فقط دو گیت فرمان‌های وب و Kotlin/PostgreSQL را پوشش می‌دهد. بازبینی مستقل، CI راه‌دور و آزمون محیط هدف برای پذیرش باقی‌اند.
